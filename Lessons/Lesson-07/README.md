# Lesson 07 – Consume NestJS REST API với ReactJS (CRUD)

## Mục tiêu bài học

* Hiểu cách frontend làm việc với REST API
* Thấy được dữ liệu thật từ backend NestJS

## Init dự án ReactJS (phục vụ demo API)

* Khởi tạo ReactJS bằng Vite
* Cấu trúc tối thiểu cho CRUD
* Các package cần thiết
  * React Router
  * Axios
  * React Query
  * Antd Design

## Kết nối ReactJS với API NestJS

* Client – Server trong REST API
* Axios instance
* Service layer gọi API

## Xây dựng giao diện CRUD

* Hiển thị danh sách dữ liệu
* Thêm mới dữ liệu
* Xóa dữ liệu
* Chỉnh sửa dữ liệu
* Loading & Error state
* Alert / Notification
